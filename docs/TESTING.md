## 游戏内验收

1. 两端替换旧版 JAR，使用协议 3；同一端只保留一个 dialog 模组。
2. 把 examples/guard.json 放入 config/velovn/dialogs，执行 dialog reload。
3. 两名玩家分别选择 A、B，再次点击同一个 NPC，确认各自进入不同开场。
4. 重复开场检查随机台词池；dialog refresh 应更新当前数据而不重抽本次台词。
5. 使用 LP 给其中一人配置 story.vip，确认只有其能看到对应选项；选项出现后撤销权限，提交应被拒绝并刷新。
6. 在 D9 检查正文中的 xconomy 变量。对其经济系统的更新完成后，下一节点或显式 refresh 应读取当前值。
7. 玩家重登与正常重启后检查阵营变量；本服存档之外的跨服复制不在当前实现范围内。
8. 播放期间修改剧本并 reload，旧会话继续其原始定义，新开场使用新定义；错误配置不替换旧目录。
9. 检查点击、空格、自动与 Ctrl 都仅提交一次有效动作，历史和图片仍正常显示。

## 范围

当前持久化的是本服玩家变量。活动会话仍在内存中，断线后重新开场；尚未实现跨服变量同步、会话接管或经济动作的分布式去重。
